# Smart Contract Assignment: Notepad / Notebook Contract

## Assignment Title

**Build a Simple Notepad Smart Contract Using Solidity**

## Objective

Create a smart contract that acts like a simple digital notebook where:

* The deployer becomes the owner of the notebook.
* The owner can create and save notes.
* Anyone can read the owner's name.
* Anyone can read the saved note.

---

# Assignment Requirements

Create a Solidity smart contract that should:

### 1. Store the Owner’s Name

* The contract owner should provide their name during deployment.
* Save the name permanently on the blockchain.

### 2. Create Notes

* Allow the owner to write and save a note.
* The note should be stored as a string.

### 3. Retrieve Data

Implement functions to:

* Get the owner's name.
* Get the saved note.


---

# Technical Requirements

* Use **Solidity version ^0.8.30**
* Use:

  * `constructor`
  * `string`
  * `public/private variables`
  * `functions`
